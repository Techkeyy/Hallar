# Hallar

Proof before pitch. Hallar helps product builders find public problems they can credibly address, then prepares useful browser-grounded evidence before engagement.

## Official starting state

This is the current source at the owner-authorized official build start. The UI was checked locally at desktop/mobile widths with reduced motion. Earlier integration and preparation evidence stays private and is not represented as a fresh official deployed run. Fresh deployment and normal-flow validation are pending. Commit dates are generated normally; no earlier Git history is fabricated.

## Flow

Product URL → source-grounded editable brief → Agent37 scout → real Monid Reddit discovery → OpenAI qualification → associated public-asset inspection → observed/inferred/suggested/limitations dossier → original conversation. Weak fits and missing evidence remain rejected or insufficient.

## Development

Node 24 and npm are used. Run npm ci, npm run typecheck, npm run build. The Next.js UI can run locally with npm run dev. Full scouting requires this app/server in a configured Agent37 runtime with private AGENT37_API_KEY, MONID_API_KEY and OPENAI_API_KEY values; .env.local is never uploaded or committed. Agent37 supplies execution, Monid supplies Reddit data, and OpenAI supplies product understanding and fit/proof reasoning. No separate database is required; session/job files persist on the retained host.

## Scope and limits

The currently demonstrated source is Reddit. The proof recipe is a narrow CSS/web-performance check on explicitly associated public assets. A capability match is not proof the product fixes the site. No plugin is applied, no production benefit or physical-phone/Lighthouse score is promised. Model judgments can be wrong, public assets can fail, and a run can legitimately produce no qualified opportunities.

The private local review endpoint is gated by loopback/environment settings; it is not a public demo or live-result fallback. Raw work/evidence, runtime files, operator ledger, credentials and screenshots are excluded from Git.
